============================================================
PHASE 5 MAIN OBJECTIVE
============================================================

Transform the existing "Request Service" button into a
REAL job-request workflow.

A customer must be able to:

1. Find a provider.
2. Select the provider.
3. Click Request Service.
4. Describe the job.
5. Select where the job is required.
6. Add relevant details.
7. Upload photos where appropriate.
8. Select preferred timing/availability.
9. Review the request.
10. Submit the request.
11. Receive confirmation.
12. Track the request.
13. Provider receives the request.
14. Provider can review it.
15. Provider can accept/respond/decline according to
   the job-request state machine.
16. Customer can see the provider's response.
17. Prepare the request for quotation in the next phase.

IMPORTANT:

Do not create fake submissions.

A successful submission must create a real JobRequest
database record.
