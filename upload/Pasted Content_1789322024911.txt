============================================================
PHASE 6 OBJECTIVE
============================================================

Build a complete, professional quotation workflow.

The customer should be able to:

1. Submit a service request.
2. Provider receives request.
3. Provider responds/interested.
4. Provider creates a quotation.
5. Provider adds quotation items.
6. System calculates totals automatically.
7. Provider sends quotation.
8. Customer receives notification.
9. Customer opens quotation.
10. Customer reviews itemized pricing.
11. Customer accepts or declines.
12. Provider receives the decision.
13. Job Request and quotation timeline are updated.
14. The system prepares the accepted quotation for the
    future payment phase.

The complete Phase 6 flow is:

JOB REQUEST
      ↓
PROVIDER RESPONSE
      ↓
CREATE QUOTE
      ↓
ADD QUOTE ITEMS
      ↓
CALCULATE TOTAL
      ↓
SEND QUOTE
      ↓
CUSTOMER NOTIFIED
      ↓
CUSTOMER REVIEWS
      ↓
ACCEPT / DECLINE
      ↓
PROVIDER NOTIFIED

PART 2 — QUOTE ELIGIBILITY
============================================================

A provider must not be able to create a quotation
for an arbitrary Job Request.

A provider may create a quote only when:

- provider is authenticated
- provider account is active
- provider is authorized
- Job Request exists
- provider is the targeted provider
- customer owns the request
- request is in a quote-eligible state
- provider has responded appropriately
- request is not cancelled
- request is not declined
- request is not completed
- request is not already committed to an incompatible
  quotation state

All rules must be enforced server-side.
