    75→PHASE 5 MAIN OBJECTIVE
    76→============================================================
    77→
    78→Transform the existing "Request Service" button into a
    79→REAL job-request workflow.
    80→
    81→A customer must be able to:
    82→
    83→1. Find a provider.
    84→2. Select the provider.
    85→3. Click Request Service.
    86→4. Describe the job.
    87→5. Select where the job is required.
    88→6. Add relevant details.
    89→7. Upload photos where appropriate.
    90→8. Select preferred timing/availability.
    91→9. Review the request.
    92→10. Submit the request.
    93→11. Receive confirmation.
    94→12. Track the request.
    95→13. Provider receives the request.
    96→14. Provider can review it.
    97→15. Provider can accept/respond/decline according to
    98→   the job-request state machine.
    99→16. Customer can see the provider's response.
   100→17. Prepare the request for quotation in the next phase.
   101→
   102→IMPORTANT:
   103→
   104→Do not create fake submissions.
   105→
   106→A successful submission must create a real JobRequest
   107→database record.
