    30→   437→- [ ] No cover has >40% dead whitespace at the bottom

    35→   442→
    36→   443→## S3.9 - Percentage Positioning Requires Known-Size Container
    37→   444→
    38→   445→**Problem:** `top: XX%` resolves against containing block’s height. If height is undefined (all children absolutely positioned), percentages collapse and elements stack.
    39→   446→
    40→   447→**Iron rule:** Container with `top: XX%` children MUST have deterministic height (`height: 100%`, `inset: 0`, or `top` + `bottom` pair).
    41→   448→
    42→   449→```css
    43→   450→/* ✅ Safest: flat structure with px values */
    44→   451→.cover { position: relative; width: 794px; height: 1123px; }
    45→   452→.kicker { position: absolute; top: 225px; left: 95px; }
    46→   453→.title  { position: absolute; top: 292px; left: 95px; }
    47→   454→
    48→   455→/* ✅ OK: wrapper with inset:0 gives it known height */
    49→   456→.content-left { position: absolute; inset: 0; width: 55%; }
    50→   457→.title { position: absolute; top: 26%; }  /* 26% of 1123px ✓ */
    51→   458→
    52→   459→/* ❌ BANNED: wrapper without height, percentage is undefined */
    53→   460→.content-left { position: absolute; left: 12%; top: 0; width: 55%; }
    54→   461→.title { position: absolute; top: 26%; }  /* 26% of WHAT? → overlap */
    55→   462→```

   472→   879→**Layout rules:**
   473→   880→1. **Border frame**: 2.5pt solid black, inset ~5% from all page edges (40px left/right, 56px top/bottom on A4 at 96dpi). This is the defining visual element.
   474→   881→2. **Institution name**: Centered, serif, 28-34pt Bold, letter-spacing 4-6px. For CJK names, use wider letter-spacing (6px). For Latin names, use standard (3px).
   475→   882→3. **Thick divider**: 2pt solid line, 70% width, separates institution from content below.
   476→   883→4. **Document type**: 20-24pt, lighter weight than institution name, letter-spacing 3-4px. This slot differentiates document categories (e.g. "开题报告" / "Thesis Proposal" / "毕业论文" / "Graduation Design").
   477→   884→5. **Title**: Serif, 26-30pt Bold, max 3 lines, centered. Auto-wrap at 520px width.
   478→   885→6. **Structured fields**: Left-aligned label + centered underline value. Label width fixed by longest label in the set. 3-7 field rows supported. Common fields: Name/姓名, Student ID/学号, Advisor/导师, Department/院系, Major/专业.
   479→   886→7. **Date**: Centered at bottom, 14pt, letter-spacing 2px.
   480→   887→
   481→   888→**Field auto-detection:**
   482→   889→When the user provides structured metadata (name, student ID, advisor, etc.), auto-populate the fields block. When no fields are provided, omit the fields-block entirely and let the title expand vertically into the freed space.
   483→   890→
   484→   891→**Variant 06B - Double border:**
   485→   892→For extra formality (government documents, official submissions), replace the single border with a double border (outer 2.5pt + inner 1pt, 6px gap):
   486→   893→```css
   487→   894→.border-frame {
   488→   895→  border: 2.5px solid var(--c-accent);
   489→   896→  outline: 1px solid var(--c-accent);
   490→   897→  outline-offset: 6px;
   491→   898→}
   492→   899→```

   494→   901→**This template has NO background decoration layer, NO watermarks, NO gradients.** The black frame + white space IS the design.
